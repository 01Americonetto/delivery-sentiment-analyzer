# 📦 Delivery Sentiment Analyzer

Primeiro projeto desenvolvido com foco em Inteligência Artificial e Processamento de Linguagem Natural (PLN), simulando a análise de feedback de clientes em plataformas de delivery (estilo iFood).

## 🚀 Sobre o Projeto
Este script utiliza modelos de Deep Learning pré-treinados da biblioteca **Hugging Face (Transformers)** para classificar automaticamente avaliações de clientes em **POSITIVO** ou **NEGATIVO**, medindo também o nível de confiança da IA em cada predição.

## 🛠️ Tecnologias Utilizadas
* **Python**
* **Google Colab Pro**
* **Hugging Face Hub & Transformers** (Pipeline de Análise de Sentimento)
* **PyTorch**
